저장 흐름

1. 대상 선택개인 모임은 게스트 입력, 클럽 모임은 멤버 선택 또는 게스트 입력
2. 상태 선택참석·대기·불참 중 하나 선택
3. 서버 검증관리자 권한, 중복, 정원, 마감·대진표 상태 확인
