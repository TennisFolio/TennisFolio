# 클럽별 실력 등급 관리 설계

## 목표

클럽 관리자가 클럽 고유의 실력 등급을 관리하고, 클럽원을 등록하거나 수정할 때 등급을 선택할 수 있게 한다. 등급을 아직 정하지 않은 클럽원은 `미정` 상태로 유지할 수 있다.

## 범위

- 클럽 생성과 수정 화면에서 등급 추가, 이름 변경, 순서 변경, 삭제를 지원한다.
- 클럽별 등급 수는 0~10개로 제한한다.
- 등급은 `level` 값이 높을수록 높은 실력으로 해석한다.
- 클럽원 등록과 수정 화면에서 해당 클럽의 등급 또는 `미정`을 선택한다.
- 기존 자유 입력 실력 메모인 `skillNote`는 제거한다.

대량 등록, 등급별 통계, 대진 생성에 등급을 반영하는 일은 이 기능 범위에 포함하지 않는다.

## 사용자 흐름

```text
클럽 생성 또는 수정
  -> 관리자가 등급을 0~10개 추가하고 이름과 순서를 정함
  -> 시스템이 현재 등급 수에 맞춰 높은 등급부터 N~1의 level을 부여함
  -> 클럽 저장
  -> 클럽원 등록 또는 수정에서 등급 또는 미정을 선택
  -> 클럽원 저장
```

```text
클럽 수정에서 등급 삭제
  -> 해당 등급으로 배정된 클럽원을 모두 미정으로 변경
  -> 등급 삭제
  -> 클럽 저장
```

## 도메인 및 데이터 모델

### ClubSkillTier

`ClubSkillTier`는 한 클럽에 속한 실력 등급이다.

- `id`: 내부 식별자
- `club`: 소속 `Club`
- `name`: 클럽 안에서 고유한 등급 이름
- `level`: 높을수록 높은 실력인 내부 계산값

클럽마다 최대 10개까지 생성할 수 있다. 등급 이름은 10자 이하여야 하며, 빈 이름과 같은 클럽 안의 중복 이름은 허용하지 않는다. 등급이 N개면 관리자가 정한 순서대로 N부터 1까지 `level`을 다시 부여한다. 예를 들어 A조, B조, C조, D조 순서의 4개 등급은 각각 4, 3, 2, 1이다.

### ClubMember

`ClubMember`에 nullable `skillTier` 연관관계를 둔다.

- `skillTier`가 있으면 해당 클럽의 등급에 배정된 상태다.
- `skillTier`가 `null`이면 `미정` 상태다.
- 기존 `skillNote` 컬럼, 엔티티 필드, DTO/API 필드, 프런트엔드 입력과 표시는 제거한다.

클럽원에게 다른 클럽의 `skillTierId`를 배정하려는 요청은 거부한다.

## 저장 규칙

- 클럽 생성 시 등급은 선택 사항이다. 등급 없이 클럽을 만들 수 있다.
- 클럽 수정 시에도 등급을 추가·변경·정렬·삭제할 수 있다.
- 등급 삭제 시 그 등급을 참조하는 활성·비활성 클럽원의 `skillTier`를 모두 `null`로 바꾼 뒤 등급을 삭제한다.
- 클럽 및 등급 변경은 하나의 트랜잭션으로 처리한다.
- 클럽 수정 권한과 등급 관리 권한은 기존 `ClubAccessService`의 관리자 규칙을 따른다.

## API 및 화면 경계

### API

- `POST /api/clubs`, `PATCH /api/clubs/{clubPublicId}` 요청에 클럽 등급 목록을 포함한다.
- 기존 생성 응답의 `publicId` 전용 계약과 수정의 빈 응답 계약은 유지한다.
- `GET /api/clubs/{clubPublicId}` 상세 응답은 등급 ID, 이름, `level`로 구성된 클럽 등급 목록을 제공한다.
- `POST/PATCH /api/clubs/{clubPublicId}/members` 요청과 응답은 nullable `skillTierId`와 선택된 등급 정보를 제공한다.

등급 편집을 별도 API로 나누지 않고 클럽 생성·수정 저장에 함께 포함해, 이름·순서·삭제를 한 번에 반영한다.

### 프런트엔드

- `ClubCreateView`, `ClubEditView`에 `클럽 등급` 섹션을 추가한다.
- 섹션은 등급 추가, 이름 수정, 위·아래 이동을 통한 순서 변경, 삭제를 제공한다. 화면은 `level` 내림차순으로 표시한다.
- `ClubMemberForm`은 자유 입력 실력 메모 대신 등급 선택 UI를 제공한다. 기본값은 `미정`이다.
- 클럽원 목록에서는 선택된 등급을 표시하고, 정렬 또는 필터 기능은 후속 범위로 남긴다.

## 검증 계획

- 등급 없이 클럽을 생성·수정할 수 있다.
- 등급을 10개까지 추가할 수 있고 11번째 등급은 거부한다.
- 빈 이름, 10자 초과 이름, 클럽 내 중복 등급 이름을 거부한다.
- 변경한 순서에 맞춰 `level`이 N~1로 다시 부여되고, 조회와 클럽원 선택 UI가 `level` 내림차순으로 표시된다.
- 클럽원은 자기 클럽의 등급만 선택할 수 있으며, `미정`으로 저장할 수 있다.
- 등급 삭제 시 해당 등급의 클럽원이 모두 `미정`으로 전환된다.
- `skillNote`가 API 계약과 화면에서 더 이상 노출되지 않는다.

## 설계 검토

- 등급은 `ClubSkillTier`로 독립시켜 클럽마다 다른 명명 체계와 순서를 지원한다.
- 클럽원은 nullable 연관관계만 가지므로 미평가 상태를 별도 상태값 없이 표현한다.
- 등급 변경을 클럽 저장에 포함해 화면의 편집 단위를 단순하게 유지한다.
- 등급 삭제 시 클럽원을 미정으로 전환하므로 관리자의 작업을 막지 않으며, 삭제 후에도 클럽원 데이터는 보존된다.
